# Pilotage Idem

Thème de la barre latérale de Zen, aux couleurs du dashboard « Pilotage Idem » : fond bleu-gris, onglet actif en bleu, dossiers colorés par catégorie.

Réglage disponible : **Apparence** (Automatique, Clair ou Sombre).

Les couleurs de dossiers suivent la couleur choisie pour chaque dossier ; sans couleur, elles sont attribuées selon la position du dossier.
